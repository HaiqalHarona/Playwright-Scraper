===========================================
  E-COMMERCE SNIPE BOT - SETUP INSTRUCTIONS
===========================================

ONE-TIME SETUP (do this once):

1. Open Command Prompt or PowerShell
2. Navigate to where you want the project:
   cd Desktop

3. Clone the repo:
   git clone https://github.com/HaiqalHarona/Commisioned-Bot.git
   OR if you already have the project folder, navigate to it directly

4. Enter the project folder:
   cd E-Commerce_SnipeBot  (or whatever your folder is named)

5. Create virtual environment and install everything:
   python -m venv .venv
   .venv\Scripts\python.exe -m pip install -r requirements.txt
   .venv\Scripts\python.exe -m playwright install chromium

6. Copy .env.example to .env and fill in your settings:
   copy .env.example .env
   (then open .env in Notepad/VSCode and fill in your account details)

   Important settings to configure:
   - STORE_NAME: Set to "Lazada"
   - ACTION: "buy", "scrape", or "buy_scrape"
   - ACCOUNT_X_URL: Product URL to target
   - ACCOUNT_X_EMAIL: Your account email
   - ACCOUNT_X_PASSWORD: Your account password
   - PROXY_URL: Optional proxy (format: http://proxy.example.com:8080 or http://username:password@proxy.example.com:8080)
   - CAPMONSTER_CLOUD: Optional CapMonster API key for captcha solving

   See README_USER_FRIENDLY.md for detailed explanations of all settings.


EVERY TIME THERE'S AN UPDATE (pull latest changes):

1. Open Command Prompt in the project folder
2. Run:
   git pull

3. If requirements.txt changed, reinstall:
   .venv\Scripts\python.exe -m pip install -r requirements.txt


TO RUN THE BOT:

   .venv\Scripts\python.exe main.py

   Make sure your virtual environment is activated or use the full path as shown above.

TROUBLESHOOTING:

- If you get "python not recognized", ensure Python is installed and added to PATH
- If playwright fails to install browsers, run: playwright install --force chromium
- For proxy issues, verify your proxy URL format is correct
- Check the logs in data/logs/ for detailed error information
